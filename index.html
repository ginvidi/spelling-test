About the voices

The Google British voice sounds the same on every phone, tablet and computer. It needs an internet connection. It's the free voice from Google Translate, so Google could change or block it at any time.

If it can't be reached, the page uses this device's own voice so the test carries on. You can also pick a device voice from the list to use offline.
